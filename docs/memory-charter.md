# 기억 헌장 (Memory Charter) v1

무엇이 기억이 되는가 — 이 문서와 추출 프롬프트(server/ai/prompts.ts)와
로컬 필터(src/capture/extractLocal.ts)는 같은 규칙의 세 표현이다.
셋 중 하나를 바꾸면 나머지 둘도 바꾼다.

## 기억이 되는 것

6개월 뒤 맥락 없이 읽어도 이해되고(자기완결), 사용자가 **다시 필요로 할** 것:

- 결정 (무엇을 하기로/안 하기로 했는가)
- 방법 (how-to, 단계, 요령)
- 사실 (검증 가능한 주장)
- 추천 (장소, 도구, 사람, 책)
- 아이디어 (착상, 가설)

원문이 실제로 말한 것만. 추론·보강·번역 금지 — 한국어 원문은 한국어 기억.

## 기억이 되지 않는 것 (포장이지 내용이 아님)

- 행동 유도문: "팔로우하세요", "저장해 두세요", "링크는 프로필에"
- 해시태그·멘션 더미
- 인사말, 광고 문구
- 원문을 요약만 하는 메타 문장 ("이 글은 ~에 대한 글이다")
- URL 그 자체

빈 결과가 소음 채우기보다 낫다.

## 중복의 처리 — 강화(reinforcement)

같은 생각이 다시 도착하면 **두 번 쓰지 않되, 반드시 센다**:
`times_seen + 1`. 세 번 저장한 생각은 어떤 랭킹 휴리스틱보다 정직한
중요도 신호다. UI는 이 수를 ×N 배지로, 인스펙터 칩으로, (예정) 지도
크기와 다이제스트로 보여준다. 삭제도 침묵도 아닌 축적.

## 관련성의 표시

기억 상세는 가장 가까운 기억(코사인 상위, 지도에 선을 긋는 것과 같은
문턱 RELATES_TO_MIN_SIMILARITY)을 "관련 기억"으로 보여준다. 같은 출처의
형제는 제외 — 함께 도착한 것은 출처이지 관련성이 아니다.

## 확신도

애매하게 추출된 것(confidence 낮음)은 저장하되 조용히. 버리면
"캡처는 유실되지 않는다"(스펙 §7.4)가 깨진다.
